# nothing2a-ram-tuner
Nothing 2a RAM Tuner is a lightweight root module that helps the Nothing Phone (2a) hold more apps in memory and switch between them faster. It tunes swappiness, filesystem cache pressure and swap read-ahead, and turns on Android's cached-app freezer so background apps stop using CPU. It doesn't kill apps or drop caches, so apps you return to resume instead of cold-starting. 

Flash on Magisk/KernelSU
